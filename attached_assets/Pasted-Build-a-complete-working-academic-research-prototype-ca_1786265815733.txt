10. DEA ARBITRATION ENGINE
==================================================

THIS IS THE CORE RESEARCH CONTRIBUTION.

Do NOT allow the LLM to make the final arbitration decision.

Implement DEA as deterministic Python code.

Formula:

V_score =
(alpha * Q_grade)
+
(beta * S_rel)
+
(gamma * T_recent)
-
(delta * P_risk)

Where:

Q_grade = evidence quality
S_rel = patient-specific relevance
T_recent = evidence recency
P_risk = patient-specific risk

Normalize all parameters to a consistent range such as 0-1.

Make the weights configurable.

Default:

alpha = 0.35
beta  = 0.30
gamma = 0.15
delta = 0.20

IMPORTANT:
The system must display the values used for every candidate.

Example:

Treatment A:
Q_grade = 0.90
S_rel = 0.80
T_recent = 0.70
P_risk = 0.90

Treatment B:
Q_grade = 0.80
S_rel = 0.90
T_recent = 0.95
P_risk = 0.20

Calculate both scores using Python.

The LLM must not override the DEA result.
