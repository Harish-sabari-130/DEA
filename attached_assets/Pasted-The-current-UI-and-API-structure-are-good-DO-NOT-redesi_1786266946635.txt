10. DEA
==================================================

KEEP THE CURRENT DEA IMPLEMENTATION.

Do not allow an LLM to override it.

Formula:

V_score =
(alpha * Q_grade)
+
(beta * S_rel)
+
(gamma * T_recent)
-
(delta * P_risk)

Default:

alpha = 0.35
beta = 0.30
gamma = 0.15
delta = 0.20

Make the weights configurable.

Display all four components and the final score.

The score MUST be calculated in deterministic Python.

Add unit tests proving the same inputs always produce the same score.
